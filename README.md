# 🌙 Sleep Tracker — Telegram-бот для отслеживания сна

**Sleep Tracker** — Telegram-бот на Python для отслеживания режима сна, сохранения истории, анализа продолжительности сна и формирования персональной статистики.

Главная цель проекта — разработать интеллектуальную систему, которая сможет автоматически определять предполагаемое время засыпания и пробуждения пользователя, анализировать его режим сна и предоставлять удобную статистику.

Проект развивается от простого Telegram-бота до полноценной системы мониторинга сна с веб-интерфейсом, визуализацией данных, интеграциями и элементами машинного обучения.

> 🚧 **Статус проекта:** MVP — базовая версия работает, ведётся активная разработка.

## 🎯 Цели проекта

- Автоматизировать ведение дневника сна.
- Минимизировать необходимость ручного ввода данных.
- Сохранять историю сна пользователей.
- Анализировать продолжительность и регулярность сна.
- Предоставлять статистику в удобном формате.
- Визуализировать изменения режима сна.
- Прогнозировать особенности режима на основе накопленных данных.
- Изучать современные технологии Backend, Data Science, Machine Learning и DevOps на практике.

## ✨ Реализованные возможности

### 💤 Учёт сна

- Регистрация начала сна командой `/sleep`.
- Регистрация пробуждения командой `/wake`.
- Автоматический расчёт продолжительности зарегистрированного периода.
- Сохранение данных в SQLite.
- Привязка записей к Telegram ID пользователя.

### 📅 История сна

- Просмотр последних 7 записей через `/history`.
- Отображение даты, времени засыпания и пробуждения.
- Форматирование дат с русскими названиями месяцев.
- Вывод продолжительности сна в часах и минутах.

### 📊 Статистика

- Получение статистики командой `/stats`.
- Расчёт средней продолжительности сна по последним 7 записям.
- Определение самого длинного периода сна.
- Определение самого короткого периода сна.
- Исключение некорректных нулевых значений из расчётов.

### 👤 Поддержка пользователей

- Идентификация через Telegram ID.
- Раздельное хранение записей разных пользователей.
- Получение персональной истории и статистики.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd sleeping-tracker
```

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка окружения

Создайте файл `.env` и укажите токен Telegram-бота, полученный через BotFather.

Название переменной должно соответствовать тому, которое используется в коде проекта.

```env
BOT_TOKEN=your_telegram_bot_token
```

### 5. Запуск

```bash
python bot.py
```

Перед запуском необходимо создать таблицу `sleep_records` с помощью логики инициализации базы данных проекта.

## 🔐 Безопасность и конфиденциальность

Данные о режиме сна относятся к персональной информации пользователя.

Основные принципы проекта:

- Не хранить токены и секреты в исходном коде.
- Не публиковать `.env` и рабочую базу данных.
- Ограничивать доступ пользователей к чужим записям.
- Использовать параметризованные SQL-запросы.
- Предусмотреть удаление пользовательских данных.
- Не собирать данные об активности без согласия пользователя.
- Защищать сессии Telegram при использовании MTProto.
- Не использовать результаты анализа как медицинскую диагностику.
