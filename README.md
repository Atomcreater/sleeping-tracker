# 🌙 Telegram Sleep Tracker

**Telegram Sleep Tracker** — учебный проект Telegram-бота на Python для отслеживания режима сна, хранения истории и анализа статистики с использованием SQLite.

Проект создаётся для изучения Python, SQL, Telegram Bot API, Git и практик разработки программного обеспечения.

## 🚀 Возможности

**Реализовано:**
- Ручной ввод времени начала и окончания сна.
- Автоматический расчёт продолжительности сна.
- Сохранение записей в SQLite.
- Просмотр истории сна.
- Расчёт средней, минимальной и максимальной продолжительности сна.

**В планах:**
- Управление функциями через Telegram-бота.
- Команды `/start`, `/help`, `/sleep`, `/history`, `/stats`.
- Автоматизация отслеживания сна.
- Анализ режима сна за неделю и месяц.
- Визуализация статистики.

## 🛠 Технологии

- **Python** — основная логика приложения.
- **SQLite** — хранение данных.
- **SQL** — запросы и аналитика.
- **Telegram Bot API** — интерфейс взаимодействия с пользователем.
- **Git / GitHub** — контроль версий.
- **GitHub Desktop** — управление репозиторием.
