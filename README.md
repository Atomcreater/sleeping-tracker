# 🌙 Sleep Tracker — Telegram-бот для отслеживания сна

**Sleep Tracker** — Telegram-бот на Python для отслеживания режима сна, сохранения истории, анализа продолжительности сна и формирования персональной статистики.

Главная цель проекта — разработать интеллектуальную систему, которая сможет автоматически определять предполагаемое время засыпания и пробуждения пользователя, анализировать его режим сна и предоставлять удобную статистику.

Проект развивается от простого Telegram-бота до полноценной системы мониторинга сна с веб-интерфейсом, визуализацией данных, интеграциями и элементами машинного обучения.

> 🚧 **Статус проекта:** рабочий MVP — ручной учёт, история, статистика, анализ активности iPhone и Telegram-бота, подтверждение и исправление обнаруженных интервалов. Автоматические уведомления проходят проверку.

---

## 🎯 Цели проекта

- Автоматизировать ведение дневника сна.
- Минимизировать необходимость ручного ввода данных.
- Сохранять историю сна пользователей.
- Анализировать продолжительность и регулярность сна.
- Предоставлять статистику в удобном формате.
- Визуализировать изменения режима сна.
- Прогнозировать особенности режима на основе накопленных данных.
- Изучать современные технологии Backend, Data Science, Machine Learning и DevOps на практике.

## ✨ Реализованные возможности

### 💤 Учёт сна

- Регистрация начала сна командой `/sleep`.
- Регистрация пробуждения командой `/wake`.
- Автоматический расчёт продолжительности зарегистрированного периода.
- Сохранение данных в PostgreSQL (Neon).
- Привязка записей к Telegram ID пользователя.

### 📅 История сна

- Просмотр последних 7 записей через `/history`.
- Отображение даты, времени засыпания и пробуждения.
- Форматирование дат с русскими названиями месяцев.
- Вывод продолжительности сна в часах и минутах.

### 📊 Статистика

- Получение статистики командой `/stats`.
- Расчёт средней продолжительности сна по последним 7 записям.
- Определение самого длинного периода сна.
- Определение самого короткого периода сна.
- Исключение некорректных нулевых значений из расчётов.

### 🔎 Экспериментальный анализ активности

- Получение событий активности iPhone через автоматизации iOS Shortcuts и HTTP API на FastAPI.
- Регистрация взаимодействий пользователя с Telegram-ботом.
- Поиск предполагаемых интервалов сна на основе событий активности.
- Объединение близких интервалов с учётом кратковременной ночной активности.
- Сохранение обнаруженных интервалов в таблице `detected_sleep`.
- Фоновый мониторинг и подготовка уведомлений о новых интервалах.
- Проверка алгоритма в ходе разработки; полноценное автоматическое тестовое покрытие требует актуализации.

### ✅ Подтверждение и исправление сна

- Просмотр обнаруженных интервалов и подтверждение их пользователем.
- Пошаговое исправление даты и времени засыпания или пробуждения через кнопки Telegram.
- Проверка пересечений с существующими записями перед сохранением.
- Защита от повторного сохранения уже подтверждённого интервала.
- Отмена редактирования без изменения базы данных.

### 🔔 Фоновые уведомления

- Добавлены очередь уведомлений и статусы обработки в PostgreSQL.
- Реализован код отправки уведомлений Telegram и обработки ошибок.
- **В процессе проверки:** фактическая доставка, повторные попытки после сбоев и предотвращение зависания статуса `sending`.

> **Ограничение:** Telegram Bot API не позволяет боту получать полную историю онлайна пользователя. Отсутствие взаимодействий с ботом **не доказывает**, что пользователь спал. Результаты автоматического анализа — экспериментальная оценка, а не измерение сна или медицинская диагностика.

### 👤 Поддержка пользователей

- Идентификация через Telegram ID.
- Раздельное хранение записей разных пользователей.
- Получение персональной истории и статистики.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Atomcreater/sleeping-tracker.git
cd sleeping-tracker
```

### 2. Создание окружения и установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для Windows активация: `.venv\Scripts\activate`.

### 3. Настройка окружения

Создайте `.env` с токеном Telegram-бота и параметрами подключения к PostgreSQL. Конкретные имена переменных должны совпадать с теми, которые используются в `main.py`, `app/db/connection.py` и `app/api/api.py`. Например, токен бота:

```env
BOT_TOKEN=your_telegram_bot_token
```

Не публикуйте реальные токены, пароли, строки подключения и ключи API. Для работы мониторинга также могут требоваться идентификатор пользователя и параметры авторизации запросов от iPhone — сверяйтесь с текущим кодом.

### 4. Локальный запуск

```bash
python main.py
```

Приложение запускает Telegram-бота, HTTP API и фоновый мониторинг. Для приёма событий iPhone API должен быть доступен по сети и корректно настроен в автоматизациях iOS.

### 5. Docker

В репозитории есть `Dockerfile` и `docker-compose.yml`. Перед запуском проверьте передачу переменных окружения, доступность PostgreSQL и сетевой адрес API. Параметры запуска зависят от конфигурации развёртывания.

## 🔐 Безопасность и конфиденциальность

Данные о режиме сна относятся к персональной информации пользователя.

Основные принципы проекта:

- Не хранить токены и секреты в исходном коде.
- Не публиковать `.env` и рабочую базу данных.
- Ограничивать доступ пользователей к чужим записям.
- Использовать параметризованные SQL-запросы.
- Предусмотреть удаление пользовательских данных.
- Не собирать данные об активности без согласия пользователя.
- Защищать сессии Telegram при использовании MTProto.
- Не использовать результаты анализа как медицинскую диагностику.
